## 什么是 Linux？为什么你需要了解它？

如果你刚接触服务器或者听说过"命令行"这个词，你可能会好奇：Linux 到底是什么？

**Linux** 不是 Windows 或 macOS 那样的桌面系统，而是一个**操作系统内核**——它是计算机硬件和软件之间的桥梁。我们平时说的"装一个 Linux"，通常指的是安装一个 **Linux 发行版**（Distribution），比如 Ubuntu、Debian、CentOS 等。

这些发行版相当于"Linux 内核 + 软件包集合"——把操作系统核心和常用的工具打包在一起，给你一个开箱即用的系统。

### Linux 和 Windows 的根本区别

| 概念 | Windows | Linux |
|------|---------|-------|
| 文件路径 | `C:\Users\你的名字\Desktop` | `/home/你的名字/桌面` |
| 盘符 | C 盘、D 盘…… | 没有盘符，一切从 `/` 开始 |
| 软件安装 | 下载 .exe 安装包 | 通过包管理器一键安装 |
| 系统核心 | 闭源，微软维护 | 开源，全球开发者共同维护 |
| 用户权限 | 默认管理员 | 普通用户 + `sudo` 提权 |

最大的思想差异在于：**Linux 把一切视为文件**。硬盘是文件（`/dev/sda`），键盘输入是文件（`/dev/stdin`），甚至连进程信息也是文件（`/proc`）。这个思想贯穿整个系统的使用。

## 命令的基本格式

Linux 命令遵循统一的格式，理解这个格式之后，遇到任何新命令都能快速上手：

```text
命令名  [选项...]  [参数...]
```

- **命令名**：要执行的程序，如 `ls`、`cp`、`grep`
- **选项**：以 `-` 或 `--` 开头，调整命令的行为，如 `ls -l`（长格式）、`ls -a`（显示隐藏文件），也可以合并成 `ls -la`
- **参数**：命令的操作对象，通常是文件名或目录名

```bash
# 例子：用长格式列出 /home 目录下的所有文件
ls -la /home
#  │  │    └── 参数：要查看的目录
#  │  └────── 选项：长格式 + 显示隐藏文件
#  └───────── 命令名
```

> **提示**：大多数命令都内置了帮助。用 `命令 --help` 看简短说明，用 `man 命令` 看完整手册。

## 文件系统：一棵倒挂的树

Linux 的文件系统是一棵从根目录 `/` 开始的目录树，没有 C 盘、D 盘的概念。所有东西——包括你后来插入的 U 盘——都会挂载在这棵树的某个分支下。

```text
/                   # 根目录，一切的起点
├── /bin            # 系统基础命令（ls, cp, mv……）
├── /boot           # 启动引导文件
├── /dev            # 设备文件（硬盘、键盘、鼠标）
├── /etc            # 系统配置文件
├── /home           # 用户的家目录
│   └── /home/你的名字   # 你的个人文件夹
├── /opt            # 第三方软件安装位置
├── /tmp            # 临时文件（重启后清空）
├── /usr            # 用户软件和库
│   ├── /usr/bin    # 更多常用命令
│   └── /usr/local  # 手动安装的软件
├── /var            # 可变数据（日志、缓存、数据库）
│   └── /var/log    # 日志文件，排查问题来这里
└── /root           # root 用户的家目录
```

新手最需要认识的三个目录：
- **`/home`** — 你的个人文件都在这里，相当于 Windows 的 `C:\Users`
- **`/etc`** — 系统配置，改设置时经常要进来
- **`/var/log`** — 系统日志，出问题时来这翻看

### 绝对路径 vs 相对路径

路径是定位文件的地址。有两种表示方式：

- **绝对路径**：从根目录 `/` 开始写，如 `/home/andy/file.txt`。无论你当前在哪个目录，绝对路径都指向同一个文件。
- **相对路径**：从当前目录开始写，如 `./file.txt`（当前目录下的文件）、`../file.txt`（上一级目录下的文件）。

```bash
# 假设你在 /home/andy 目录下，下面两条命令等价：
cat /home/andy/f1.sh       # 绝对路径
cat f1.sh                  # 相对路径

# 特殊目录符号
.   # 当前目录
..  # 上一级目录
~   # 当前用户的家目录
-   # 上次所在的目录
```

## 终端和 Shell：你与系统的对话窗口

### 为什么 Linux 偏爱命令行？

Windows 用户习惯了图形界面操作，但 Linux 的世界里命令行是**一等公民**。原因很简单：

1. **服务器没有显示器**——大多数 Linux 运行在远程服务器上，你只能通过终端连接
2. **命令行更高效**——熟练之后，敲几个字母比鼠标点来点去快得多
3. **自动化**——命令可以写成脚本，重复劳动一键搞定
4. **精确可控**——每个命令的输出都可以被下一个命令处理，像搭积木一样

### Shell 是什么？

终端（Terminal）只是一个窗口，真正理解你命令的是 **Shell**。你可以把 Shell 理解为一个翻译官——你把人类可读的命令告诉它，它翻译给操作系统执行。

最常见的 Shell 是 **Bash**，Ubuntu 默认使用它。近年来 **Zsh** 也越来越流行。

当你打开终端看到类似 `用户名@主机名:当前目录$` 的提示符时，就说明 Shell 已经就绪。提示符末尾的 `$` 表示普通用户，`#` 表示 root 管理员。

## 常用命令：新手的工具箱

### 导航与文件查看

```bash
# 我在哪里？
pwd                         # 显示当前目录的绝对路径

# 这里有什么？
ls                          # 列出当前目录下的文件
ls -l                       # 详细信息：权限、大小、修改时间
ls -la                      # 包括隐藏文件（. 开头的文件）
ls -lh                      # 文件大小以人类可读格式显示（K, M, G）
ll                          # Ubuntu 中 ll 等同 ls -l

# 去哪里？
cd 目录名                    # 进入某个目录
cd ..                       # 回到上一级
cd ~                        # 回到你的家目录
cd /                        # 去根目录
cd -                        # 回到上次所在的目录
```

### 文件名通配符

通配符帮助你批量匹配文件，是命令行效率的关键：

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `*` | 匹配任意长度字符 | `ls *.txt` — 所有 .txt 文件 |
| `?` | 匹配单个字符 | `ls f?le` — file, fale 等 |
| `[abc]` | 匹配括号中任一字符 | `ls [abc]*` — 以 a、b 或 c 开头的文件 |
| `[a-z]` | 匹配范围内的字符 | `ls [a-z]*` — 以小写字母开头的文件 |
| `[!abc]` | 匹配不在括号中的字符 | `ls [!0-9]*` — 不以数字开头的文件 |

```bash
# 列出 /bin 下所有以 l 开头的文件
ls /bin/l*

# 列出所有扩展名为 .log 或 .txt 的文件
ls *.log *.txt

# 找出当前目录下以 f 开头、恰好 3 个字符的文件
ls f??
```

### 文件操作

```bash
# 创建
touch 文件名.txt             # 创建一个空文件，或更新已有文件的时间戳
mkdir 目录名                 # 创建一个目录
mkdir -p a/b/c              # 一次性创建多层目录

# 查看
cat 文件                     # 一次性输出全部内容（适合小文件）
less 文件                    # 分页浏览，按 q 退出，按 / 搜索
head 文件                    # 显示文件前 10 行
head -n 5 文件               # 显示文件前 5 行
tail 文件                    # 显示文件最后 10 行
tail -f 文件                 # 实时追踪文件新增内容（看日志必备）

# 复制、移动、删除
cp 源文件 目标               # 复制文件
cp -r 源目录 目标目录         # 复制整个目录
cp -b 源 目标                # 覆盖前先备份（备份文件以 ~ 结尾）
mv 源 目标                   # 移动文件，也用作重命名
rm 文件                      # 删除文件（没有回收站！）
rm -r 目录                   # 删除目录及其中所有内容
rmdir 空目录                 # 删除空目录（非空目录用 rm -r）

# 查找文件
find 目录 -name "文件名"      # 按名字查找
find 目录 -type f -size -10k # 查找小于 10KB 的普通文件
find 目录 -type d            # 只查找目录
find 目录 -name "*.log" -size +1M  # 查找大于 1MB 的日志文件
```

> **警告**：`rm` 删除的文件**没有回收站**，删了就没了。特别是 `rm -rf`，执行前确认三遍。

### 输入/输出重定向

每个命令默认从键盘读取输入（标准输入），将结果输出到屏幕（标准输出），将错误输出到屏幕（标准错误）。通过重定向可以改变这些流向：

```bash
# 输出重定向
命令 > 文件        # 将命令的输出写入文件（覆盖）
命令 >> 文件       # 将命令的输出追加到文件末尾

# 错误重定向
命令 2> 文件       # 将错误信息写入文件（覆盖）
命令 2>> 文件      # 将错误信息追加到文件末尾

# 同时重定向输出和错误
命令 > 文件 2>&1   # 正常输出和错误都写入同一个文件
命令 &> 文件       # 同上，简写形式

# 输入重定向
命令 < 文件        # 从文件读取输入
```

```bash
# 实例：将当前时间写入文件（覆盖旧内容）
date > timestamp.txt

# 实例：将当前时间追加到文件
date >> log.txt

# 实例：编译代码时，把错误信息单独保存
gcc program.c 2> errors.txt

# 实例：正常输出和错误都写入同一个日志
npm run build &> build.log
```

### 管道

管道符 `|` 把一个命令的输出直接传给下一个命令作为输入，像搭积木一样组合出强大的功能：

```bash
# 基本格式
命令1 | 命令2 | 命令3 ...

# 统计 /etc 目录下有多少个文件
ls /etc | wc -l

# 统计当前目录下各文件夹占用空间，按大小排序，只看前 5 个
du -sh * | sort -hr | head -5

# 查看占用内存最多的 5 个进程
ps aux | sort -nrk 4 | head -5

# 看日志中的错误并按出现次数排序
grep "ERROR" /var/log/syslog | cut -d: -f2 | sort | uniq -c | sort -nr
```

### 文本处理三剑客

```bash
# grep — 搜索文本
grep "关键词" 文件名           # 在文件中搜索
grep -r "关键词" 目录          # 递归搜索整个目录
grep -i "关键词" 文件          # 忽略大小写
grep -v "关键词" 文件          # 排除匹配的行

# 实例：从日志中找所有 Error
grep "Error" /var/log/syslog

# 实例：递归搜索项目中的所有 TODO 注释
grep -r "TODO" src/

# sed — 流编辑器（查找替换）
sed 's/旧内容/新内容/g' 文件    # 替换文本（仅输出，不修改文件）
sed -i 's/旧/新/g' 文件        # 直接在文件中替换

# awk — 数据分析
awk '{print $1}' 文件         # 打印每行第一个字段
awk -F: '{print $1, $3}' /etc/passwd  # 以冒号为分隔符，打印第1、3列
```

### 文件类型与链接

Linux 中有多种文件类型，`ls -l` 输出的第一个字符标识了类型：

| 字符 | 类型 | 说明 |
|------|------|------|
| `-` | 普通文件 | 文本、图片、程序等 |
| `d` | 目录 | 文件夹 |
| `l` | 符号链接 | 类似 Windows 的快捷方式 |
| `b` | 块设备 | 硬盘等 |
| `c` | 字符设备 | 键盘、鼠标等 |

**符号链接（软链接）** 和 **硬链接** 是 Linux 中很有特色的概念：

```bash
# 创建符号链接（类似 Windows 快捷方式）
ln -s 目标文件 链接名

# 创建硬链接（同一文件的不同名字，共享同一个 inode）
ln 目标文件 链接名

# 查看文件的 inode 号
ls -i 文件名
```

两者的关键区别：

| | 符号链接 | 硬链接 |
|------|---------|--------|
| 本质 | 存放目标路径的指针 | 指向同一 inode 的别名 |
| 跨文件系统 | 可以 | 不可以 |
| 链接目录 | 可以 | 不可以 |
| 源文件删除后 | 链接失效（变红） | 数据依然存在 |

```bash
# 实例
ln -s /usr/bin/python3 /usr/bin/python   # 创建软链接
ln important.txt important_backup.txt    # 创建硬链接

# 两个硬链接拥有相同的 inode 号，说明它们本质上是同一个文件
ls -li important.txt important_backup.txt
```

为什么用硬链接？当你删了原文件，硬链接还能正常访问数据——它们共享同一个 inode，只有当所有链接都被删除后数据才会真正被清除。

### 归档与压缩

```bash
# tar — 打包
tar -cf 包名.tar 文件1 文件2...    # 创建归档（c=create, f=file）
tar -tf 包名.tar                  # 查看归档内容（t=list）
tar -rf 包名.tar 新文件           # 向归档中追加文件（r=append）
tar -xf 包名.tar                  # 解包（x=extract）
tar -xf 包名.tar -C 目标目录       # 解包到指定目录

# 打包 + gzip 压缩（一步到位）
tar -czf 包名.tar.gz 文件...      # 打包并用 gzip 压缩
tar -xzf 包名.tar.gz              # 解压
tar -xzf 包名.tar.gz -C 目标目录   # 解压到指定目录

# gzip — 单独压缩
gzip 文件                         # 压缩（生成 文件.gz）
gzip -d 文件.gz                   # 解压
gzip -9 文件                      # 最大压缩率（1 最快，9 最小）
```

### 权限管理

Linux 是一个多用户系统，每个文件和目录都有读（r）、写（w）、执行（x）三种权限，分别针对**所有者（u）**、**用户组（g）**和**其他人（o）**。

```bash
# 查看权限
ls -l                        # 输出如 -rw-r--r-- 的权限字符串

# 字母模式修改权限
chmod u+x 脚本.sh             # 所有者加执行权限
chmod g-w 文件                # 用户组去掉写权限
chmod o-r 文件                # 其他人去掉读权限

# 数字模式（r=4, w=2, x=1，三位相加）
chmod 755 文件                # rwxr-xr-x：所有者全权，其他人只读和执行
chmod 644 文件                # rw-r--r--：所有者读写，其他人只读（普通文件常用）
chmod 775 目录                # rwxrwxr-x：所有者与组全权（共享目录常用）

# 修改所有者
chown 用户:组 文件            # 更改文件的所有者和用户组
```

权限字符串速读：`-rw-r--r--` 拆成 `-`（类型） + `rw-`（所有者：读+写） + `r--`（组：只读） + `r--`（其他人：只读）。

### 用户与用户组管理

Linux 是多用户系统，用户信息记录在几个关键文件中：

| 文件 | 内容 |
|------|------|
| `/etc/passwd` | 用户账户信息（用户名、UID、家目录、Shell） |
| `/etc/shadow` | 加密后的密码及过期策略 |
| `/etc/group` | 用户组信息 |
| `/etc/gshadow` | 用户组密码 |

```bash
# 用户管理（需要 sudo）
sudo useradd 用户名                   # 创建用户
sudo useradd -m 用户名                # 创建用户并自动创建家目录
sudo useradd -g 组名 用户名           # 创建用户并指定主组
sudo passwd 用户名                    # 设置/修改用户密码
sudo usermod -d /新/home 用户名       # 修改用户家目录
sudo usermod -c "全名" 用户名         # 修改用户全名
sudo userdel 用户名                   # 删除用户（保留家目录）
sudo userdel -r 用户名                # 删除用户及家目录

# 用户组管理
sudo groupadd 组名                    # 创建用户组
sudo groupadd -g 2000 组名            # 指定 GID 创建用户组
sudo groupdel 组名                    # 删除用户组
sudo gpasswd -a 用户名 组名           # 将用户加入组
sudo gpasswd -d 用户名 组名           # 将用户从组中移除
groups 用户名                         # 查看用户属于哪些组

# 切换用户
su - 用户名                           # 切换到指定用户
su -                                  # 切换到 root 用户
```

### 进程管理

```bash
# 查看进程
ps                          # 当前终端进程
ps aux                      # 所有进程的详细信息
ps aux | sort -nrk 3 | head # 按 CPU 占用排序，看前几名

# 实时监控

kill -9 进程ID               # 强制杀死（最后的武器）

# 查看进程打开的文件
lsof -p 进程ID               # 查看指定进程打开的文件
lsof -u 用户名               # 查看指定用户打开的文件
```

### 后台任务

当你在终端运行一个长时间任务时，可以把它放到后台，不阻塞终端：

```bash
# 命令后面加 & 直接在后台启动
命令 &

# Ctrl+Z 暂停当前任务，然后用 bg 放到后台继续运行
bg          # 把最近暂停的任务放到后台
bg %2       # 把编号为 2 的任务放到后台

# 查看后台任务列表
jobs
jobs -l     # 附带 PID

# 把后台任务调回前台
fg          # 调回最近一个
fg %2       # 调回编号为 2 的

# 让程序在后台不受挂断信号影响
nohup 长时间命令 &

# 终止后台任务
kill %2     # 用任务编号终止
```

### 任务调度

#### 一次性任务 — `at`

```bash
# 先确保 atd 服务在运行
sudo systemctl start atd

# 2 分钟后执行指定操作
echo "mkdir /tmp/test" | at now + 2 minutes

# 在指定时间执行
at 23:59 2026-12-31
# 然后输入要执行的命令，Ctrl+D 结束

# 查看待执行的任务队列
atq

# 删除任务（用任务编号）
atrm 2
```

#### 周期性任务 — `crontab`

```bash
# 编辑当前用户的定时任务
crontab -e

# 查看已有的定时任务
crontab -l
```

crontab 的时间格式：`分 时 日 月 星期`

```text
# ┌──────── 分钟 (0 - 59)
# │ ┌────── 小时 (0 - 23)
# │ │ ┌──── 日 (1 - 31)
# │ │ │ ┌── 月 (1 - 12)
# │ │ │ │ ┌ 星期 (0 - 7, 0 和 7 都表示周日)
# │ │ │ │ │
# * * * * * 要执行的命令
```

```bash
# 每 5 分钟执行一次
*/5 * * * * /path/to/script.sh

# 每天早上 8:30 执行
30 8 * * * /path/to/script.sh

# 每周一凌晨 2 点执行
0 2 * * 1 /path/to/backup.sh

# 每月 1 号 0 点执行
0 0 1 * * /path/to/monthly.sh
```

### 服务管理 — systemctl

现代 Linux 使用 systemd 管理系统服务，systemctl 是它的控制命令：

```bash
# 查看所有服务状态
systemctl list-units --type=service

# 查看服务详细信息
systemctl status 服务名

# 启动 / 停止 / 重启
sudo systemctl start 服务名
sudo systemctl stop 服务名
sudo systemctl restart 服务名

# 开机自启
sudo systemctl enable 服务名     # 设为开机自启
sudo systemctl disable 服务名    # 取消开机自启

# 查看服务是否已开启开机自启
systemctl is-enabled 服务名
```

### 磁盘与挂载

```bash
# 查看磁盘使用情况
df -h                        # 查看已挂载分区的使用情况
df -hT                       # 同时显示文件系统类型
du -sh 目录名                 # 查看目录占用的总空间
du -sh * | sort -hr | head   # 当前目录下最大的几个文件夹

# 查看内存
free -h                      # 查看内存使用

# 查看磁盘分区信息
sudo fdisk -l                # 列出所有磁盘和分区

# 格式化分区
sudo mkfs -t ext4 /dev/sdb1  # 格式化为 ext4 文件系统

# 挂载与卸载
sudo mount /dev/sdb1 /mnt/data    # 挂载分区到指定目录
sudo umount /mnt/data             # 卸载
sudo umount /dev/sdb1             # 也可按设备名卸载
```

临时挂载在重启后会失效。要让挂载永久生效，需要编辑 `/etc/fstab` 文件添加一行配置。

### 网络相关

```bash
# 测试网络连通性
ping 域名或IP                 # 按 Ctrl+C 停止

# 查看网络配置
ip addr                      # 查看本机 IP 地址

# 下载文件
curl -O 网址                  # 下载文件，保留原始文件名
wget 网址                     # 另一个下载工具

# 远程连接（SSH）
ssh 用户名@服务器IP            # 连接到远程服务器

# 传输文件
scp 本地文件 用户名@IP:远程路径  # 上传文件到服务器
scp 用户名@IP:远程路径 本地路径  # 从服务器下载文件
```

### 包管理（软件安装）

Ubuntu 使用 **APT**（Advanced Package Tool）来管理软件：

```bash
# 更新软件列表（每次安装前建议先执行）
sudo apt update

# 安装软件
sudo apt install 软件名
# 例：sudo apt install nginx    安装 Nginx
# 例：sudo apt install git       安装 Git
# 例：sudo apt install htop      安装 htop

# 升级已安装的软件
sudo apt upgrade

# 卸载软件
sudo apt remove 软件名           # 卸载但保留配置文件
sudo apt purge 软件名            # 连配置文件一起删除

# 搜索软件
apt search 关键词
```

`sudo` 是 "superuser do" 的缩写，**以管理员身份执行**。Linux 中普通用户不能随意改动系统，需要临时提权时就加 `sudo`。

## 实用技巧

### Tab 键补全

输入命令或路径时按 **Tab** 键，Shell 会自动补全。这是使用 Linux 最高效的习惯，没有之一。按两下 Tab 会列出所有可能的选项。

### 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + C` | 终止当前正在运行的命令 |
| `Ctrl + D` | 退出当前 Shell / 发送 EOF |
| `Ctrl + L` | 清屏（等同于 `clear` 命令） |
| `Ctrl + R` | 搜索历史命令（最实用的快捷键） |
| `Ctrl + A` | 跳到行首 |
| `Ctrl + E` | 跳到行尾 |
| `Ctrl + Shift + +` | 终端放大字体 |
| `Ctrl + -` | 终端缩小字体 |
| `↑ / ↓` | 翻看历史命令 |

### 使用 `man` 查手册

Linux 自带完整的手册系统，遇到不会用的命令直接查：

```bash
man ls                       # 查看 ls 命令的完整手册
man grep                     # 查看 grep 的所有参数
```

按 `/` 搜索，`n` 跳到下一个结果，`q` 退出。如果你觉得 `man` 太啰嗦，试试 `tldr`（需要安装 `sudo apt install tldr`），它会给出最常用的使用示例。

### 防止 `rm` 悲剧

新手最容易犯的错就是误删文件。最简单的防护：

```bash
# 在 ~/.bashrc 中加入，让 rm 在删除前确认
alias rm='rm -i'
```

## 下一步学什么？

当你掌握了以上基础后，可以考虑：

1. **Vim 基础** — 服务器上的默认编辑器，至少学会 `i` 进入编辑、`Esc` 退出、`:wq` 保存退出
2. **Shell 脚本** — 把重复的命令写成 `.sh` 脚本，自动化日常任务
3. **Docker 入门** — 现代部署的标准方式
4. **Nginx 配置** — 搭建 Web 服务器的基础
5. **用户权限深入** — sudo 配置、ACL 访问控制
6. **Shell 环境定制** — 修改 .bashrc、提示符配色、别名设置

## 总结

Linux 的学习曲线初看陡峭，但一旦跨过最初的适应期，你会发现它的简洁和强大。记住几个原则：

- **一切皆文件** — 理解这个思想，很多概念会自然通透
- **命令行不可怕** — 每天用 5-10 个命令，一周就能形成肌肉记忆
- **学会组合** — 通配符加快操作，管道串联命令，重定向控制输出
- **遇到问题查 man 和日志** — `/var/log` 是最好的老师

你的第一台 Ubuntu 服务器已经就绪，开始动手吧。

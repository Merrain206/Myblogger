# 技术准确性核对清单

候选图产出后，**逐张**对照原文核对以下项。任何一项不通过，先修正或弃用，不得带着错误进入确认环节。

## 通用

- [ ] 图中出现的**术语**与原文一致（同一概念不用两个名字）。
- [ ] **方向/箭头**表示的因果或数据流方向正确（不要画反）。
- [ ] **层级/顺序**（如从下到上、从左到右）与原文叙述一致。
- [ ] 没有引入原文不存在的概念、组件或步骤。

## 公式与数值

- [ ] 公式**逐符号**与原文一致（下标、上标、运算符、求和范围）。
- [ ] 变量含义、维度标注正确。
- [ ] 数值、比例、坐标刻度与原文出处一致，可追溯。
- [ ] 图中结论（如"更优/更低/更快"）与原文表述一致，不夸大。

## 结构 / 流程图

- [ ] 模块划分与原文一致，没有多出或遗漏的方块。
- [ ] 调用/依赖关系的存在性与方向正确。
- [ ] 并行 vs 串行的表达正确。

## 热力图 / 数据图

- [ ] 色标（colormap）方向正确（深色=高还是低，需与原文一致）。
- [ ] 轴标签、图例、单位齐全且正确。
- [ ] 若为示意数据，必须标注"示意"或与原文明确区分，不得伪装成真实实验数据。

## 风格 vs 准确性

- [ ] **美观不得改变事实**：为了好看而简化掉的关键组件/关系需要补回或标注。
- [ ] 类比图（插画）的隐喻**不能误导**：若隐喻可能引起错误理解，改用示意结构图。

## 校验结论记录

对每张图，用一行记录：`图名 | 通过/修正后通过/弃用 | 依据（对应原文行）`。用户在确认环节可见。

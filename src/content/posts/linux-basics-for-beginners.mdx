## 什么是 Linux？为什么你需要了解它？

如果你刚接触服务器或者听说过"命令行"这个词，你可能会好奇：Linux 到底是什么？

**Linux** 不是 Windows 或 macOS 那样的桌面系统，而是一个**操作系统内核**——它是计算机硬件和软件之间的桥梁。我们平时说的"装一个 Linux"，通常指的是安装一个 **Linux 发行版**（Distribution），比如 Ubuntu、Debian、CentOS、Arch Linux 等。

这些发行版相当于"Linux 内核 + 软件包集合"——把操作系统核心和常用的工具打包在一起，给你一个开箱即用的系统。

### Linux 和 Windows 的根本区别

| 概念 | Windows | Linux |
|------|---------|-------|
| 文件路径 | `C:\Users\你的名字\Desktop` | `/home/你的名字/桌面` |
| 盘符 | C 盘、D 盘…… | 没有盘符，一切从 `/` 开始 |
| 软件安装 | 下载 .exe 安装包 | 通过包管理器一键安装 |
| 系统核心 | 闭源，微软维护 | 开源，全球开发者共同维护 |
| 用户权限 | 默认管理员 | 普通用户 + `sudo` 提权 |

最大的思想差异在于：**Linux 把一切视为文件**。硬盘是文件（`/dev/sda`），键盘输入是文件（`/dev/stdin`），甚至连进程信息也是文件（`/proc`）。这个思想贯穿整个系统的使用。

## 文件系统：一棵倒挂的树

Linux 的文件系统是一棵从根目录 `/` 开始的目录树，没有 C 盘、D 盘的概念。所有东西——包括你后来插入的 U 盘——都会挂载在这棵树的某个分支下。

```text
/                   # 根目录，一切的起点
├── /bin            # 系统基础命令（ls, cp, mv……）
├── /boot           # 启动引导文件
├── /dev            # 设备文件（硬盘、键盘、鼠标）
├── /etc            # 系统配置文件
├── /home           # 用户的家目录
│   └── /home/你的名字   # 你的个人文件夹
├── /opt            # 第三方软件安装位置
├── /tmp            # 临时文件（重启后清空）
├── /usr            # 用户软件和库
│   ├── /usr/bin    # 更多常用命令
│   └── /usr/local  # 手动安装的软件
├── /var            # 可变数据（日志、缓存、数据库）
│   └── /var/log    # 日志文件，排查问题来这里
└── /root           # root 用户的家目录
```

新手最需要认识的三个目录：
- **`/home`** — 你的个人文件都在这里，相当于 Windows 的 `C:\Users`
- **`/etc`** — 系统配置，改设置时经常要进来
- **`/var/log`** — 系统日志，出问题时来这翻看

## 终端和 Shell：你与系统的对话窗口

### 为什么 Linux 偏爱命令行？

Windows 用户习惯了图形界面操作，但 Linux 的世界里命令行是**一等公民**。原因很简单：

1. **服务器没有显示器**——大多数 Linux 运行在远程服务器上，你只能通过终端连接
2. **命令行更高效**——熟练之后，敲几个字母比鼠标点来点去快得多
3. **自动化**——命令可以写成脚本，重复劳动一键搞定
4. **精确可控**——每个命令的输出都可以被下一个命令处理，像搭积木一样

### Shell 是什么？

终端（Terminal）只是一个窗口，真正理解你命令的是 **Shell**。你可以把 Shell 理解为一个翻译官——你把人类可读的命令告诉它，它翻译给操作系统执行。

最常见的 Shell 是 **Bash**（Bourne Again Shell），Ubuntu 默认使用它。近年来 **Zsh** 也越来越流行，界面更漂亮，补全更智能。

当你打开终端看到类似 `用户名@主机名:~$` 的提示符时，就说明 Shell 已经就绪，等待你的指令。

## 常用命令：新手的工具箱

下面这些命令是你日常使用频率最高的，掌握它们就足以应付 80% 的场景。

### 导航与文件操作

```bash
# 我在哪里？
pwd                         # 显示当前目录路径

# 这里有什么？
ls                          # 列出当前目录下的文件
ls -l                       # 详细信息：权限、大小、修改时间
ls -la                      # 包括隐藏文件（. 开头的文件）
ls -lh                      # 文件大小以人类可读格式显示（K, M, G）

# 去哪里？
cd 目录名                    # 进入某个目录
cd ..                       # 回到上一级
cd ~                        # 回到你的家目录
cd /                        # 去根目录
cd -                        # 回到上次所在的目录
```

### 文件操作

```bash
# 创建
touch 文件名.txt             # 创建一个空文件
mkdir 目录名                 # 创建一个目录
mkdir -p a/b/c              # 一次性创建多层目录

# 查看
cat 文件                     # 一次性输出全部内容（适合小文件）
less 文件                    # 分页浏览，按 q 退出，按 / 搜索
head 文件                    # 显示文件前 10 行
tail 文件                    # 显示文件最后 10 行
tail -f 文件                 # 实时追踪文件新增内容（看日志必备）

# 复制、移动、删除
cp 源文件 目标               # 复制文件
cp -r 源目录 目标目录         # 复制整个目录
mv 源 目标                   # 移动文件，也用作重命名
rm 文件                      # 删除文件（没有回收站！）
rm -r 目录                   # 删除目录及其中所有内容
rm -rf 目录                  # 强制删除，不提示确认。谨慎使用！
```

> **警告**：`rm` 删除的文件**没有回收站**，删了就没了。特别是 `rm -rf`，执行前确认三遍。

### 权限管理

Linux 是一个多用户系统，每个文件和目录都有读（r）、写（w）、执行（x）三种权限，分别针对所有者、用户组和其他人。

```bash
# 查看权限
ls -l                        # 输出如 -rw-r--r-- 的权限字符串

# 修改权限
chmod +x 脚本.sh              # 给文件添加可执行权限（最常用）
chmod 755 文件                # 数字模式：所有者全权，其他人只读

# 修改所有者
chown 用户:组 文件            # 更改文件的所有者
```

权限字符串速读：`-rw-r--r--` 拆成 `-`（类型） + `rw-`（所有者） + `r--`（组） + `r--`（其他人）。

### 进程管理

```bash
# 查看进程
ps aux                       # 列出所有正在运行的进程（经典用法）

# 实时监控
top                          # 类似任务管理器，按 q 退出
htop                         # top 的升级版，界面更友好（需要安装）

# 杀死进程
kill 进程ID                   # 优雅地终止进程
kill -9 进程ID                # 强制杀死（最后的武器）
```

### 磁盘和空间

```bash
df -h                        # 查看磁盘使用情况
du -sh 目录名                 # 查看某个目录占用了多少空间
du -sh * | sort -hr | head   # 找出当前目录下哪些文件夹最大
free -h                      # 查看内存使用
```

### 包管理（软件安装）

Ubuntu 使用 **APT**（Advanced Package Tool）来管理软件：

```bash
# 更新软件列表（每次安装前建议先执行）
sudo apt update

# 安装软件
sudo apt install 软件名
# 例：sudo apt install nginx    安装 Nginx Web 服务器
# 例：sudo apt install git       安装 Git
# 例：sudo apt install htop      安装 htop

# 升级已安装的软件
sudo apt upgrade

# 卸载软件
sudo apt remove 软件名
sudo apt purge 软件名           # 连配置文件一起删除

# 搜索软件
apt search 关键词
```

这里的 `sudo` 是 "superuser do" 的缩写，**以管理员身份执行**。Linux 中普通用户不能随意改动系统，需要临时提权时就加 `sudo`。

### 网络相关

```bash
# 测试网络连通性
ping 域名或IP                 # 按 Ctrl+C 停止
# 例：ping google.com

# 查看网络配置
ip addr                      # 查看本机 IP 地址
# 或旧命令：
ifconfig

# 文件下载
curl -O 网址                  # 下载文件（最常用）
wget 网址                     # 另一个下载工具

# 远程连接（SSH）
ssh 用户名@服务器IP            # 连接到远程服务器
# 例：ssh root@82.157.193.186

# 传输文件
scp 本地文件 用户名@IP:远程路径  # 上传文件到服务器
scp 用户名@IP:远程路径 本地路径  # 从服务器下载文件
```

### 文本处理三剑客

这三个命令是 Linux 文本处理的灵魂，组合使用威力无穷：

```bash
# grep — 搜索文本
grep "关键词" 文件名           # 在文件中搜索
grep -r "关键词" 目录          # 递归搜索整个目录
grep -i "关键词" 文件          # 忽略大小写

# 实例：从日志中找所有 Error
grep "Error" /var/log/syslog

# sed — 流编辑器（查找替换）
sed 's/旧内容/新内容/g' 文件    # 替换文本内容
sed -i 's/旧/新/g' 文件        # 直接在文件中替换

# awk — 数据分析
awk '{print $1}' 文件         # 打印每行第一个字段
```

管道符 `|` 可以把一个命令的输出传给下一个命令，组合出强大功能：

```bash
# 统计某个文件夹下有多少个 .log 文件
ls -l | grep ".log" | wc -l

# 查看占用内存最多的 5 个进程
ps aux | sort -nrk 4 | head -5
```

## 实用技巧

### Tab 键补全

输入命令或路径时按 **Tab** 键，Shell 会自动补全。这是使用 Linux 最高效的习惯，没有之一。按两下 Tab 会列出所有可能的选项。

### 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + C` | 终止当前正在运行的命令 |
| `Ctrl + D` | 退出当前 Shell / 发送 EOF |
| `Ctrl + L` | 清屏（等同于 `clear` 命令） |
| `Ctrl + R` | 搜索历史命令（最实用的快捷键） |
| `Ctrl + A` | 跳到行首 |
| `Ctrl + E` | 跳到行尾 |
| `↑ / ↓` | 翻看历史命令 |

### 使用 `man` 查手册

Linux 自带完整的手册系统，遇到不会用的命令直接查：

```bash
man ls                       # 查看 ls 命令的完整手册
man grep                     # 查看 grep 的所有参数
```

按 `/` 搜索，`n` 跳到下一个结果，`q` 退出。

如果你觉得 `man` 太啰嗦，可以试试 `tldr`（需要安装 `sudo apt install tldr`），它会给出最常用的使用示例。

### 防止 `rm` 悲剧

新手最容易犯的错就是误删文件。最简单的防护：

```bash
# 在 .bashrc 中加入，让 rm 在删除前确认
alias rm='rm -i'
```

## 下一步学什么？

当你掌握了以上基础后，可以考虑：

1. **Vim 基础** — 服务器上的默认编辑器，至少学会 `i` 进入编辑、`Esc` 退出、`:wq` 保存退出
2. **Shell 脚本** — 把重复的命令写成 `.sh` 脚本，自动化日常任务
3. **systemd 服务** — 让你的程序开机自启、后台运行
4. **Nginx 配置** — 搭建 Web 服务器的基础
5. **Docker 入门** — 现代部署的标准方式

## 总结

Linux 的学习曲线初看陡峭，但一旦跨过最初的适应期，你会发现它的简洁和强大。记住三个原则：

- **一切皆文件** — 理解这个思想，很多概念会自然通透
- **命令行不可怕** — 每天用 5-10 个命令，一周就能形成肌肉记忆
- **遇到问题查 man 和日志** — `/var/log` 是最好的老师

你的第一台 Ubuntu 服务器已经就绪，开始动手吧。

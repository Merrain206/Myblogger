③ 中间件链 → FastAPI · 逐层向内传递
④ FastAPI → 依赖注入 · 解析依赖 user_api_key_auth
⑤ 依赖注入 → FastAPI · 返回 UserAPIKeyAuth
⑥ FastAPI → Pydantic · 校验请求体
⑦ Pydantic → FastAPI · 得到 ChatCompletionRequest
⑧ FastAPI → 路由函数 · 调用路由函数
⑨ 路由函数 → 客户端 · StreamingResponse —— 响应一路流回去

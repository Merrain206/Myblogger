## 一、出发：从地铁站到西溪园区

说实话，出发前我对"去阿里"这件事是有些期待的——倒不是因为什么大厂光环，而是当你读了很多论文、看了很多技术博客，突然有机会走进那些技术背后真正"跑着"的地方，那种感觉是不一样的。

西溪园区离地铁站非常近，出了站几乎不用抬头看路牌，沿路的指引标识就已经把方向安排得明明白白。我们从 **A5 门**进入——A3 是员工通道，恰好赶上十点左右的上班时间。我注意到一个细节：来往的员工大多没穿工服，步态放松，三三两两地聊着天进门，状态看起来很**松弛**。不是想象中那种人人夹着电脑神色匆匆的大厂画面，至少在那个时刻，他们看起来像是去一个自己愿意待的地方。

刚进门，迎面就是一组醒目的 **奥运五环 logo** 和**阿里 logo** 并排而立——阿里是奥运全球合作伙伴，这个标识在西溪园区里随处可见。一楼是一个宽敞通透的访客大厅，白色为主调，灯光和线条搭配得很有未来感，墙上的大屏滚动着各种技术活动的海报。而今天的主场，在二楼。

![阿里西溪园区大门](/images/blog/alibaba-campus-gate.jpg)

## 二、上午：开幕式与四个硬核 Talk

开幕式在 **A5 访客中心 212N 白马山庄** 举行。门口摆着一台类似拍立得的机器，工作人员热情地招呼我去体验——拍一张照片，可以选不同风格滤镜，打印出来做成一枚小小的**冰箱贴**。我选了一个风格拍了一张，当时没太在意，后来拿到成品的那一刻，觉得这可能是整趟旅程中最有意义的"物料收获"——不是什么贵重的东西，但每次在冰箱上看到它，都会想起这一天。

![冰箱贴](/images/blog/alibaba-fridge-magnet.jpg)

### 2.1 开场

10:15 准时开幕，技术发起人**郑波**做了开场分享。没有冗长的领导致辞，郑波的发言很干——围绕"硬核少年"这个品牌，讲了几年来技术节从内部小沙龙发展到今天这个规模的过程，以及对技术人"保持好奇、保持硬核"的期许。节奏很快，几句话之后就直接切入了正题——四个硬核技术 Talk。

### 2.2 四个 Talk，一个让我印象最深

四个 Talk 分别是：

- **《拍立淘全模态实时 Agent》**：聚焦多模态 Agent 在"以图搜货"场景下的实时推理链路，从上传图片到返回同款商品的完整 pipeline 优化。
- **《If Studio 设计专家 / 视频专家》**：面向内容创作场景的 AI 工具，能做设计稿生成和视频智能剪辑，技术上涉及多模态理解与可控生成。
- **《Coupella 智慧引擎——AIGU 生成式因果推断技术升级》**：将因果推断引入生成式 AI，用于电商场景中的 A/B 实验归因和策略决策，听起来偏 to B 的数据科学底座。
- **《Dream = 意图引擎 + Meta Model》**：淘宝搜索推荐的底层意图理解系统，让 Agent 从用户行为链中推断真实需求。

前三个各有看点，但 **Dream 意图引擎**是我整场听下来触动最深的一个——因为它用了一个极其通俗的例子，把一个复杂的技术理念讲透了。

主持人举的例子是这样的——

> 假设你想选一款 **SPF 50++** 的防晒霜。你在淘宝搜索框输入了关键词，系统返回了一堆结果。你翻了几页，点进去看了看，又退出来——没有一个让你满意。
>
> 然后你点进了一个**儿童防晒霜**的商品页面。你没有直接搜索"儿童防晒霜"，你是通过层层浏览才走到这里的。你开始翻商品详情、看成分表、浏览买家秀——全是宝妈们在讨论宝宝用后有没有过敏反应。
>
> 在这个过程中，后台的 Agent 在默默地"观察"你的行为轨迹。它从你的浏览路径中捕捉到了关键信号：你先是搜了高倍防晒，然后不满意，然后又主动深入浏览了儿童品类，对敏感肌相关的内容停留了很久。Agent 推断出——你真正要的不是一款普通的高倍防晒霜，而是一款**给宝宝的、敏感肌可用的、SPF 50++ 防晒霜**。
>
> 当你退出那个商品页面，回到搜索列表时，推荐结果已经悄然变化：不再是泛泛的高倍防晒，而是精准命中"儿童 + 敏感肌 + 高倍"的防晒产品。不出意外，你点进了 Agent 推荐的新页面，最终完成了购买。

整个过程，Agent 做的不是关键词匹配，而是**意图链推理**——它不仅看了你搜了什么，更看了你"不满意之后去了哪里"，从你的一系列行为中推断出那个你没能用搜索词准确表达的深层需求。

这和传统的"猜你喜欢"完全不在一个技术代际上。协同过滤是"跟你相似的人也买了这个"；Dream 做的是**理解你当下这一连串行为背后的意图**——不是猜测一个标签，而是在追踪一条动态变化的意图链。这在推荐系统的演进上，是一个质的飞跃。

![Dream 意图引擎](/images/blog/alibaba-dream-engine.jpg)

Talk 结束后，我在展示区看到了阿里正在孵化的 Agent 项目矩阵——从电商搜索、智能客服，到办公协同、内容创作，甚至还有面向娱乐和游戏场景的 Agent，覆盖面相当广。坦白讲，来之前我对阿里 AI 的认知还停留在"电商 + 云"的刻板印象里，而现在，阿里刷新了我的认知。

![阿里正在孵化的 Agent 项目](/images/blog/alibaba-agent-projects.jpg)

## 三、中午：一场不太信服的"人机对决"

开幕式结束后，是一场**人类 vs Agent 表演赛**。游戏是阿里自研的一款模拟经营类游戏，两个真人玩家对战两个 Agent。

说实话，去之前我心里是押 Agent 赢的。毕竟这种规则明确、需要快速计算最优策略的游戏，天然适合 AI 发挥。

结果呢——**人类在落后之后反超，拿了冠军。**

听起来很燃对吧？但我和身边的朋友都隐约觉得这个反转**有点太刻意了**。不是说不相信人类能赢，而是整个过程的戏剧性太强，让我们不禁怀疑是不是为了节目效果设计过的。当然，也可能只是我们自己想多了。

不过话说回来，这种"人机对决"的形式本身是有意义的——它让我们直观地看到当前的 Agent 在具体任务中能做到什么程度，而不是只看 benchmark 上的数字。

![人类 vs AI 表演赛](/images/blog/alibaba-human-vs-ai.jpg)

开幕式收尾后，进入了中午的**技术市集**环节，地点设在 A5 访客中心一楼的展厅。说是"市集"，其实更像是各个技术团队把自己的项目摆出来"练摊"——每个摊位一个小展台，你可以走过去上手体验，和做项目的同学直接聊。做拍立淘的团队旁边摆着实物商品让你拍照测试，If Studio 那边可以直接上传一段视频看 AI 怎么自动剪辑。氛围比上午的正式报告轻松不少，端着咖啡边走边看的人很多，交流也更随意、更真实。

12:30 到 13:30 是午餐时间，园区的食堂选择不少，但我的注意力还在上午那些 Talk 的余味里没散出来。

## 四、下午：博见社——见大佬，也见自己

下午的**博见社**是这一天含金量最高的部分。地点回到报告厅，14:00 准时开始。

开场致辞由**高阳**（中国人工智能学会会士）和**郑波**（淘天集团首席科学家）共同带来。两位的致辞都很简短，但信息量不小——高阳老师从学会的视角回顾了 Agent 研究从冷门到火热的历程，郑波则从产业侧补充了阿里对 Agent 技术投入的决心。两段话合在一起，恰好构成了"学术界 + 产业界"的双视角开场。

### 4.1 四个主题报告

| 时间 | 报告 | 讲者 |
|------|------|------|
| 14:10 | 《基于大语言模型的智能体》 | 郝建业（天津大学教授） |
| 14:30 | 《大语言环境下的强化学习》 | 温颖（上海交大长聘教轨副教授） |
| 14:50 | 《大规模智能体系统的三项基础能力》 | 周浩（清华大学智能产业研究院副研究员） |
| 15:10 | 《智能体 Harness 的设计与演进：从会回答到可靠执行》 | 张航帆（上海 AI Lab 青年研究员） |

这是我目前为止，在现场范围里见到的跟 **Agent、AI、Harness** 这几个方向最相关的一批顶尖研究者。每位讲者 20 分钟，信息密度极高——

- **郝建业老师**从宏观框架切入，系统梳理了 LLM-based Agent 的架构范式，从感知-规划-执行三层模型讲起，一直延伸到多 Agent 协作的挑战。他的 PPT 里有一页"Agent 能力金字塔"让我印象很深——底层的工具调用、中层的任务规划、顶层的元认知，每一层对应着不同的技术难题。

- **温颖老师**聚焦强化学习与大语言模型的交叉地带。他提出了一个我此前没仔细想过的问题：当 Agent 的行动空间从"输出一段文本"扩展到"执行一连串工具调用"时，RL 中的 reward 信号该怎么设计？传统的稀疏 reward 在这种场景下几乎不可用，他们团队在这个方向上做了不少探索性的工作。

- **周浩老师**的题目最硬核——大规模智能体系统的"三项基础能力"。他分别拆解了通信（Agent 之间如何高效传递信息）、协调（多 Agent 如何避免冲突和死锁）、以及自适应（系统如何根据环境变化调整行为策略），每一项能力背后都有具体的实验数据和失败案例分析。这是我听得最累的 20 分钟，但也是收获最密的 20 分钟。

- **张航帆老师**来自上海 AI Lab，他的报告聚焦在 **Harness 的设计与演进**上。"从会回答到可靠执行"这个副标题精准概括了他的核心论点——当前的很多 Agent 框架能跑通 demo，但距离生产环境还有一条巨大的鸿沟。他分享了一线实验室在 Harness 设计上的踩坑经验，包括工具调用的错误恢复、长任务链的状态管理、以及 Agent 行为的安全校验。

（这些报告的详细技术内容我计划在后续 3-4 篇文章中分别深入展开，结合我拍的 PPT 照片，把每位老师讲的精华整理出来。这里只做一个全景速写。）

### 4.2 圆桌交流：从生成式 AI 到智能体进化

报告之后的**圆桌交流**是全天最让我受启发的环节。主题是"从生成式 AI 到智能体进化"，主持人谨持，参与嘉宾有韩忠义、郝建业、温颖、周浩、张航帆、郑波——学术和产业两边的主要人物都坐到了台上。

话题的走向比我想象的更自由。主持人没有准备那种"每人回答一遍"的套路问题，而是抛出一个开放性的命题之后，让嘉宾们自然地碰撞。

聊到 Agent 的落地瓶颈时，几位老师不约而同地指向了同一个问题：**可靠性**。当前的 Agent 在单步任务上表现不错，但一旦进入多步、有分支、需要纠错的场景，成功率就断崖式下降。产业方（郑波）从用户体验的角度表达了担忧——用户不会给一个"大部分时候靠谱"的 Agent 第二次机会。学术方（郝建业、温颖）则从方法论层面讨论了"可验证性"——Agent 的每一步决策，能不能被追溯到具体的依据？

聊到 Agent 的社会影响时，张航帆和谨持之间的讨论格外精彩。一个观点让我至今还在回味——"AI 时代最稀缺的不是会写 prompt 的人，而是知道该让 AI 去解决什么问题的人。"这句话把全场的技术讨论拉回了一个更根本的维度。

有几个瞬间，坐在台下的我能明显感觉到——**这些讨论不是在"汇报成果"，而是在"试探边界"**。他们聊的很多东西还没有标准答案，甚至没有人能确定哪种路线是对的。这种真诚的不确定感，在如今 AI 圈铺天盖地的"all in agent"叙事中，显得格外珍贵。

![圆桌交流会](/images/blog/alibaba-roundtable.jpg)

## 五、收获：不止知识

如果要我给这一天打分，我会打 **9 分**。扣掉的那 1 分是时间太紧——一天之内只能逛西溪园区这一小块地方，阿里内部还有太多的角落和团队想去看看，但限于日程没能成行。

但 9 分是实打实的。

**知识的收获**——从 Dream 意图引擎的工程化实践，到四位教授对 Agent 各个维度的深度拆解，再到圆桌上那些关于可靠性和可验证性的坦诚讨论，每一个环节都在反复告诉我同一件事：**Agent 不再只是论文里的一个词了。** 它正在被工程化、被产品化，正在走进真实用户的每一次搜索、每一次点击。而与此同时，它离"真正可靠"还有多远，在场最前沿的研究者们也还在摸索。

**更有意思的收获，是友谊。** 在会场里我遇到了一位以媒体通道进来的朋友，我们相邻而坐，休息间隙聊了起来。她的视角和我完全不同——我是从技术实现的角度在听报告，她更多在思考"这些技术会怎样影响普通人的生活"。这种跨角度的对话很有意思，我们聊了很久，后来交换了微信。

活动结束之后，我又陆续向她请教了很多关于 AI 行业的问题——从技术趋势到职业路径、从实习方向到不同赛道的真实状态。她在媒体侧积累的行业视野，对我这个还在校门里的学生来说，是书本和论文里完全没有的东西。这种**意料之外的连接**，某种程度上比任何一场报告都更实际地影响了我。
